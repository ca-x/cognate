# Cognate 组件更新

计划于 2026-11-01 发布服务端 `server-v0.2.0`、CLI `cli-v0.2.0` 和桌面端
`gui-v0.1.3`，懒猫另发 Exec LPK `0.2.0`，仅提交喵喵商店。
本文说明本版范围；实际发布状态以工作流、下载校验和商店回执为准。

## 服务端 0.2.0

1. **Gemini 配置授权**：接通已验收的固定 Gemini profile 手动配置流程，保留字段审阅、独立授权、冲突拒绝及结果核对。
2. **归档校验**：新增 Linux `cache verify` 离线单归档校验，检查权限、SHA256 和归档内容，不读取主密钥、不改动原件。
3. **备份修正**：接受合法的空 SQLite WAL 索引，避免把该状态误判为无效备份输入；不代表完整恢复能力已完成。

镜像提供 Linux amd64/arm64，使用 `ghcr.io/ca-x/cognate:server-v0.2.0`，不创建隐式
`latest`。离线归档校验只支持现有 legacy 数据布局；运行代、恢复或 intent 痕迹会被拒绝，
不会选择可能错误的归档目录。缓存修复与自动回收仍未提供。

## CLI 0.2.0

1. **Gemini 手动应用**：Linux amd64 支持固定 Gemini 0.61.0、Node 26.13.0 组合，逐项审阅并批准配置，支持核对、恢复与还原。
2. **清晰的操作指引**：配置命令帮助补齐 Gemini target，并保留 Codex 已有固定 profile 的预览、授权和冲突检查。
3. **完整许可随包交付**：六份归档保留 Codex 许可，并附 Gemini 原版 LICENSE 与完整第三方声明。

Gemini 支持不扩大到其它版本、平台、OAuth 管理或 GUI 本机应用。提供 Linux/macOS/Windows
amd64/arm64 下载，实际账号交互、安装和同步支持仍以已验收的 Linux 范围为准；跨平台登录
与 CLI OIDC 闭环仍待完成。下载后使用随包 `SHA256SUMS` 核验。

## Desktop 0.1.3

1. **安装包更新**：重新打包当前已验收的 MyGo 原生客户端，各平台安装包保留 Codex 许可并增加 Gemini 原版 LICENSE 与完整第三方声明。

这是安装包维护更新，不宣称新增 MyGo Gemini/Codex 本机配置应用。保留已有技能浏览、
订阅与配置资产管理能力。macOS 仍仅 ad-hoc 签名且未公证，Windows 安装包仍未签名；
构建与包内容检查不等于各平台真人安装及完整交互验收。

## 懒猫 0.2.0

沿用 Exec 运行方式、显式私有数据目录、程序内主密钥初始化与首次管理员向导，
升级不覆盖原管理员密码或主密钥。包装仓库固定本次服务端标签和准确源提交，
新增 Gemini 两份许可材料。仅发布喵喵商店，官方商店保持关闭。

## 升级与已知限制

- 升级前另行备份数据库、归档与原主密钥；已有数据缺失密钥时仍拒绝生成替代密钥。
- 不保证直接换回旧二进制即可安全降级，新格式的操作记录可能被旧程序拒读。
- 完整灾难恢复、自动保留回收、完整 cc-switch/Magpie 导入、全部 agent 本机应用、Pack 配置消费与自动应用仍未完成。
- MyGo 新增本机配置应用、Pack schema 实施及恢复闭环仍在独立开发，不包含在本版中。
- 懒猫平台 OIDC、真机升级数据保留及 Mac/Windows 完整运行验收仍待验证。
- 写入结果不明时先核对原操作，不自动重放；反馈不要附带 token、密码、主密钥或完整私有配置。

本版不会移动旧标签，也不把正式组件分发当成完整需求验收。剩余任务见 `TODO.md`。
