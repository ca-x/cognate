# Cognate Server 0.5.0

本次是 Web 工作空间的界面与交互更新，沿用 React、TanStack 与 Radix，未更换框架或增加动效依赖。

- **资料库优先**：仓库列表与技能详情直接成为主内容，不再先经过添加、导入两块大表单。添加仓库使用 Radix 弹层，关闭保留草稿，成功后自动选择新仓库；停止等待仍不等于撤销服务端提交。
- **按需展开**：Magpie、cc-switch 与 npx skills 导入收在可展开入口中，折叠不卸载导入状态；归档校验摘要按需查看，发布管理放在技能内容之后，默认私有和显式发布确认不变。
- **配置浏览**：新增按 Agent 与名称筛选、计数及一键清除，筛选仅作用于已读取元数据，不读取配置草稿、不切换 provider 或应用设备配置。
- **工作空间**：导航区分技能与管理，增加当前位置、账号标识，统一间距与材质；复用原有快速弹层反馈，展开箭头使用短过渡，键盘与 reduced-motion 不增加动效等待。
- **切页反馈**：使用 TanStack 的代码预加载和稳定占位；悬停/聚焦导航只预热页面模块，不提前读取私有业务数据或发起写入。

目标镜像：`ghcr.io/ca-x/cognate:server-v0.5.0`（Linux amd64/arm64），不更新 `latest`。
懒猫 Exec 采用独立 `0.5.0`，仅发布喵喵商店，官方商店保持关闭。
CLI 保持 0.2.0、MyGo GUI 保持 0.1.3；本次 Web 改进不冒充原生 GUI 更新。

## 升级与范围

沿用 0.4.0 的数据库、主密钥、管理员、OIDC 和导入边界，无数据库或 RPC schema 变更。
升级前仍应备份原数据和主密钥，保留原私有数据目录，不重新执行首次管理员初始化。
这不是全部产品 backlog 的完成声明；设备配置应用、完整导入矩阵和其它未完成项仍见 `TODO.md`。
懒猫真机升级、平台 OIDC 与实际商店切换不能由合成浏览器测试替代。
