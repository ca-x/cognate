# Cognate 0.6.2

状态：Server 与懒猫 0.6.2 已发布，喵喵已接受；回执线上版本仍为 0.6.1。

Web 交互与动效维护版本，仅发布 Server 与懒猫 Exec 包。最终分发、校验和商店回执
见 `RELEASE-v0.6.2-VERIFICATION.md`；CLI 0.3.0、MyGo 0.1.4 保持不变。

- 登录故事区、公开目录和 GitHub 来源卡片增加局部追光；登录流程说明一次性渐入，
  同步图标仅在真实请求中旋转。键盘、触摸/笔和“减少动态效果”均有静态降级，
  不给搜索、输入或高频操作增加等待。
- 导入和仓库搜索支持一键清空并保留焦点；明确显示筛选数量、总量与已选数量，
  没有可导入结果时禁用无效批选，继续复用成熟框架组件。
- 备份设置明确区分未保存草稿、已同步和应用中状态。重新读取前确认，保留失败时的
  非秘密草稿，取消旧读取以防覆盖新设置，并在重载后恢复键盘焦点。
- 保留主题、中英切换、窄屏、200% 字号及 reduced-motion。按需适配 React Bits，
  不新增动画运行时依赖、Canvas、CDN 或持续 RAF。

## 升级与范围

沿用既有账号、数据路径、原主密钥与 OIDC 设置，不重新初始化。管理员备份配置仍然
在线生效、无需重启；凭据不回显、revision CAS、任务忙与结果不明确时拒绝重配等
安全门禁不变。Linux 同一数据目录仍只允许一个服务端，恢复密钥仍需单独保管。

React Bits 的许可是 MIT + Commons Clause，并非无条件 MIT；完整原文嵌入服务端，
可匿名读取 `/assets/react-bits-LICENSE.txt`，懒猫另附 `REACT-BITS-LICENSE.txt`。
项目根许可不替代该第三方许可。

本版本不扩大完整备份恢复、第三方配置映射、原生 GUI 或平台资格。浏览器的触摸/笔
事件验证不等于实体触屏验收；懒猫店面切换、真机升级和平台 OIDC 仍须单独确认。
