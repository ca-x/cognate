# 技能、仓库与配置选择导入

仓库页默认提供三类选择导入。来源为 cc-switch schema23/24 的独立 SQLite 快照、Magpie `library.json` 或 [npx skills v3 global lock](NPX-SKILLS-IMPORT.md)；浏览器和客户端不运行 moejs，来源适配器只在服务端执行。旧版仅仓库流程仍可显式切换使用，只保留原有两种来源，旧 RPC 保留兼容。

## 使用流程

1. 选择来源和导出文件，再点击上传预览；仅选择文件不会上传。cc-switch 原始快照上限 16 MiB，Magpie 与 npx 上限 1 MiB。SQLite 必须是一致、自包含的 rollback-mode 导出，不能忽略运行中数据库的 WAL；制作方法见 [CCSWITCH-SNAPSHOT.md](CCSWITCH-SNAPSHOT.md)。整个文件可能包含凭据，只能授权上传到自己信任的服务器。
2. 分别查看技能、仓库和配置候选。三类默认都不勾选，可以选择任意非空组合；不支持的配置汇总为跳过数量，不堆叠无法区分的名称，也不会静默导入。各列可搜索与批量选择，有界滚动；技能显示关联仓库，配置显示客户端、服务地址及模型。完整字段与改名选项按需展开。当前 cc-switch provider 配置支持 Claude、Codex、Gemini、受限 Grok Build 和 [OpenCode v1](OPENCODE-IMPORT.md)，不代表其它 agent、MCP 或 instructions 已支持导入。
3. 按需要明确选择认证模式、Gemini key transport 或不冲突的配置名称，再重新预览。更改选项会使旧预览失效并清除选择。Web 的 Magpie/cc-switch 导入可在空资料库中勾选技能，先保存仓库来源与技能名称/路径引用，不等待整仓下载；仅选择技能也会保存所属仓库。已验证内容仍使用严格的仓库、分支、归档和完整技能身份绑定，不根据同名文件猜测绑定。npx 及旧客户端保留原有验证流程。
4. 阅读并确认所有排除项和内容未比较提示，勾选需要的候选后进入确认。相同原因合并成一组通俗说明，确认一组仍明确确认该组全部原始提示；不会自动代勾。取消后重勾不影响协议中的原始提示顺序。仅选仓库也可提交，不要求选择其它两类。预览与确认本身不写入导入资产或收录仓库；提交才执行选择。票据五分钟有效，过期需重新预览。
5. 完成后核对各类回执。尚未下载的来源显示在“已保存来源”区域，点击“同步技能”才下载整仓并扫描 SKILL.md；网络失败仍保留记录，可配置代理后重试。未提供路径的引用显示为待识别，不假设根目录。导入不是本机安装，也不复制源应用的本地修改。配置保存为私有资产，不自动切换 provider；来源凭据只展示是否存在，不迁移秘密值，仍需自行明确补充凭据。

## 结果与中断

- Completed 表示所选仓库及最终配置/技能引用事务完成，不表示客户端已经安装或应用。Partial 可能已收录部分仓库，不能解释为整批回滚。
- Magpie/cc-switch 的 Web 来源登记、技能来源引用和终态回执在短事务内一起提交，纯仓库导入不访问 GitHub。来源按账号、仓库与分支去重，技能来源按名称/路径去重，重复导入不重复添加；每个账号最多保存 256 个来源与合计 512 条技能来源引用。移除来源不删除已同步的技能、组合或其它内容。
- 提交后取消、断网或关闭弹窗不等于撤销。结果不确定时只查询同一操作的状态，不自动重发提交；NotObserved 也不能证明并发提交以后不会完成。
- 文件、原始字节、预览票据与未提交选项不写入 URL、浏览器存储或 TanStack 查询缓存。切换账号、来源、语言或离开页面会取消等待并清理相应状态；内存清零不保证浏览器内部副本的安全擦除。
- 文件名与大小仅在当前页面显示，用于确认已选文件，不发送给服务端或持久保存。
  Magpie 原生导出支持 `.magpie-backup`（例如 `magpie-2026-11-06.magpie-backup`）、
  `.backup` 与兼容 JSON；加密备份先在浏览器用导出密码解密，密码不发送到服务端。
- 服务端必须配置规范的 `public-origin`：生产使用 HTTPS，显式 HTTP loopback 仅供本地部署或测试。缺少配置或 origin 不合资格时，仅新三类导入 RPC 返回 FailedPrecondition，旧预览仍保留；票据只绑定已配置 origin，不能用请求 Host 或转发头代替可信配置。

协议和资源限制见 [IMPORT-SELECTION-PROTOCOL.md](IMPORT-SELECTION-PROTOCOL.md)。本功能不代替 CLI/MyGo 的完整选择导入、Pack 配置附件、明确授权后的自动应用、十四类 agent 适配或完整 F6/M6 验收。
