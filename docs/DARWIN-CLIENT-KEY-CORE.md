## 保留的失败历史

先前提交 `646fe4d451e9776577294961d18125993d553bb7` 的 [run 41117905399](https://github.com/ca-x/cognate/actions/runs/41117905399) 仍为失败、未取得运行资格。它在共用安全套件开始前触发 APFS 前置检查错误，不能记为核心算法测试失败或成功。
