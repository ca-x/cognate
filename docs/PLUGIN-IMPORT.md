# 插件导入（开发中）

插件和内置适配器仅在服务端执行，位于 `internal/server/plugin` 和 `internal/server/importer`。CLI 与 MyGo 客户端负责上传经用户选择的导出数据、选择服务端预览结果并应用下载资源；不运行 moejs，不直接通过插件读取本地第三方应用数据库。此前实验性的 `import-preview cc-switch` 和 `import cc-switch` 客户端入口已经撤下。

目前服务端内部支持 Linux 上 cc-switch 仓库和 skill 元数据的只读预览，尚无对外插件 RPC。数据库路径只能由管理员授权的服务端来源或隔离上传工作目录提供，不能接受 RPC 用户指定任意宿主路径。缺少数据库时不会创建；`HEAD`（不区分大小写）和空分支表示跟随仓库真实默认分支。仓库保留启用状态，skill 保留 ID、名称和安全目录名，不自动迁移到客户端或服务端仓库目录。

SQLite 使用只读连接和一致读事务读取有限的 `skill_repos` 行，不使用 `immutable=1`，以便看到 WAL 中已提交数据；SQLite 可能读取或创建数据库旁的 WAL/共享内存文件，所以不是零文件系统副作用。Linux 预览拒绝不可信属主或其他用户可写的数据库及 sidecar，检查父目录路径链并拒绝符号链接和不安全的可写目录；检查仍依赖路径稳定，不能阻止同 UID 非协议主体或 root 替换。其他平台的信任检查尚未实现，已有数据库会拒绝读取。预览后结果是一次观察，不承诺源数据库未继续变化。错误不包含数据库内容或插件异常消息。

内置转换模块以 MoeForge/moejs 执行，每次运行使用新 runtime，不安装文件系统或网络 API，禁用动态代码和未授权模块加载，限制源、输入、运行时间、JavaScript 内存及结果大小。已完成的 async Promise 返回其结果，拒绝或仍 pending 的 Promise 返回错误；事件循环及异步宿主 I/O 尚未接入。运行时内存限制不是进程硬上限；宿主 Go 内存和阻塞的宿主函数不由其限制。当前没有对外开放第三方插件加载，moejs 单进程隔离不能视为恶意代码的 OS 安全沙箱。

Magpie 已有服务端只读预览，可解析经验证的源格式中的仓库与已安装 skill 引用，范围与限制见 [MAGPIE-IMPORTER.md](MAGPIE-IMPORTER.md)；这不等于完整迁移或导入。manifest、上传接口与隔离工作目录、受控宿主能力、仓库真正入库、完整的 skill 迁移及客户端配置导入、Magpie 完整迁移/导入以及 npx skills/通用适配器仍未完成。敏感配置的读取、加密保存和传输尚未实现，F6/M6 未完成。
