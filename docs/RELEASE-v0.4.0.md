# Cognate Server 0.4.0

1. **OIDC 账号关联与解绑**：密码登录后启动 OIDC 默认关联当前账号，不再因缺省绑定标记创建新用户。账号页可查看关联并用本地密码取消；保留当前会话，撤销其它会话，原用户名和密码不变。OIDC-only 账号不能解绑；历史独立账号不自动合并。
2. **Magpie 界面导出**：Web 支持带密码的 `.magpie-backup`，上限 64 MiB。密码仅供浏览器 WebCrypto 解密，需要 HTTPS 或 localhost；仅上传规范化技能来源，不上传密码、打包文件或无关凭据。兼容明文 `library.json`（1 MiB）。不是完整备份恢复。
3. **cc-switch 快照兼容**：Web 支持 schema23/24、64 MiB 自包含 SQLite 快照，修复 schema23 和约 45 MiB 本机库无法预览的问题。整库会上传到受信服务端，仍须明确授权并遵循一致快照导出要求。真实本机库仅只读内存测试，未提交数据库或记录。

镜像：`ghcr.io/ca-x/cognate:server-v0.4.0`，目标 Linux amd64/arm64，不更新 `latest`。
懒猫 Exec LPK 使用独立 `0.4.0`，仅发布喵喵商店，官方关闭。
CLI 保持 0.2.0（原 16 MiB 导入限制不变），GUI 保持 0.1.3。

## 升级与边界

- 升级前备份数据库、归档及原主密钥；保留原管理员、密码、密钥与私有数据目录。
- 旧 OIDC 身份若已属于另一账号，绑定仍拒绝；不会按邮箱或用户名转移身份或数据。
- 不包含全部客户端配置导入、Magpie 打包技能文件恢复、全部 agent 应用或完整灾难恢复。
- 协议、合成浏览器和本机只读数据库测试不替代懒猫真实 provider、店面切换及真机升级测试。
- 遇到问题不要附带数据库、导出文件、密码、token 或完整私有配置。
