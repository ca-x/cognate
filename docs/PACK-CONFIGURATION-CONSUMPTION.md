# Pack 配置附件：当前只实现 P1 元数据管理

本页说明 MyGo 的所有者附件编辑。它不是完整 C7 / F12 交付声明，也不授予配置消费、
秘密读取、设备控制、订阅配置自动应用或任何 native profile 的运行资格。

## 入口和身份

在现有 **Pack 订阅** 页下方使用 **所有者配置附件**。原技能订阅、同步和后台同步保持独立。
先在账号页登录，再明确点击 **读取所有者附件**。界面用当前 origin 和进程内普通会话，
实际核验 GetSession，并读取该所有者的 Pack 列表、附件快照和全部配置资产元数据。
不是从订阅或分享令牌推断所有权；服务器仍在每次附件 RPC 中检查当前 owner。

不读取配置正文、ReadDraft 或已有秘密，不创建本机 key，不创建临时明文配置文件，
不连接 MCP，不执行插件、进程或 agent，不把站点 MCP token 当作资产凭据。
HTTP 客户端固定同源、禁止重定向和环境代理，使用受验证 TLS；会话不进入 review DTO。

## 完整有序编辑

界面显示 Pack ID、两个独立 revision、完整旧附件的 agent/kind/schema/pin/target/state，
以及所有资产类型和 schema 的元数据。资产读取上限 250、Pack 上限 100，继承现有接口额度。
资产名称旁的选择只选择元数据，不读取正文；未知 schema 和不支持类型保持只读。

明确点击 **放弃旧草稿，重新编辑** 后，从当前完整快照建立草稿；不会自动升级旧 pin。
选择一个已知 schema 1 provider，然后 **添加所选资产引用**。最多 16 项，同一 asset/target
不重复；可以选择引用、上移、下移、移除、明确清空，或者明确升级所选 pin 到已读取版本。
十四类有限元数据目标不等于十四类 native 都 Available。Unknown schema 不会有损转换。
移除引用只改附件元数据，不删除资产或其秘密。

stale、未知目标或已缺失的引用不能作为新有效引用提交。需明确升级或移除后再审阅；
读取元数据不是连接验证，也不是服务端预验证。即使读取后资产再次变化，提交仍由服务端
在原附件事务中检查 expected asset revision、所有权和有限目标。

## 审阅和一次提交

**审阅附件替换** 先重新核验完整基线，再通过 typed packattachments review 显示
origin、真实 owner、Pack ID、双 revision、完整旧/新有序引用、清空后果及确认有效期。
review 是深拷贝的非秘密 DTO，不解析或重用 CLI 终端摘要。

精确输入本次随机 `REPLACE ...` 确认文字，然后 **确认并替换一次附件**。
审阅和提交都核对 generation、身份、完整基线及新引用；确认只用一次。
提交前重读仍不替代服务器的 Pack/configuration 双 CAS 与资产版本校验。
只有收到完整有效成功回执才更新本地已读快照。保存附件不保存配置正文，不授秘密使用权，
不应用本机，更不启用后台自动配置消费。

## 冲突、Unknown、取消和离开

冲突、取消、超时或结果不明不会自动重放。写前即将当前审阅标为已消耗；失去有效回执时
保留旧草稿只读。即使服务端当前状态恰好匹配，也不能据此宣称某次 Unknown 成功。

明确 **读取所有者附件** 仅做只读核对：保留旧草稿，不重发替换，不自动恢复写权限。
需要再次明确 **放弃旧草稿，重新编辑**，基于新快照重新编辑、重新审阅、重新确认。
编辑期间 Pack 选择锁定；显式放弃草稿后才可以切换，避免隐式丢弃。

取消审阅或 Escape 保留元数据草稿，不发送写入。导航保留草稿，但使旧审阅失效。
更换账号/origin 或退出会清除该身份私有状态；取消任务也清除普通会话，需重新登录。
Close 取消自有会话与网络任务，Model.Wait 加入所有 worker/连接关闭，丢弃旧 generation
的 completion；不会因为关窗而补发写入。已经提交的 SQL 事务不能靠取消追回。

## 资格和后续边界

P1 已完成非作者限定审查及与选择导入的主线组合。新增共享生命周期回归覆盖两个编辑器的
真实 App/TLS/SQLite、取消/身份切换/关闭及双向 Unknown 隔离；当前组合普通 Linux 窗口另
完成真实登录、审阅确认和一次元数据替换读回。这不关闭下述消费或跨平台门禁。

P1 的定向验证区分真实 App/TLS/SQLite、MyGo tester 和普通原生 binary 前门。
tester 深浅主题、键盘、reduced-motion、文字 200% 是原生渲染测试，不称浏览器 zoom 或
跨平台窗口运行证明。六目标 CGO0 编译也不等于六平台运行资格。

完整 B+D5 的持久 consent/policy、设备双 PoP enrollment、受权交接/真实 reported diff、
独立秘密批准、明确 opt-in 自动应用、撤销、恢复、schema 升级和包装入口均不在 P1 中实现。
普通 share/匿名技能订阅没有因此携带配置秘密；native prepare/authorize/consume 契约、
Codex40/Gemini41、schema/T4/R3/LPK 和本机应用代码在本片不变。
