# Cognate Server 0.3.0

1. **离线归档修复**：停止服务后，可用可信本机备份补回缺失归档或替换损坏归档，并保留损坏原件。
2. **中断后显式续接**：保存命令输出的修复 ID，中断后先校验归档，再按该 ID 检查和续接，不自动重放或清理残留。

镜像：`ghcr.io/ca-x/cognate:server-v0.3.0`，提供 Linux amd64/arm64，不更新 `latest`。
懒猫 Exec LPK 使用独立的 `0.3.0` 版本，仅发布喵喵商店，官方商店关闭。

本版只更新服务端；CLI 保持 `0.2.0`，Desktop 保持 `0.1.3`，不重复打包无代码变更的组件。
尚未验收的 MyGo 本机配置应用、Pack 自动配置和完整恢复不包含在本版中。

## 使用与升级

- 升级前备份数据库、归档及原主密钥；已有数据缺失密钥时仍拒绝生成替代密钥。
- 新命令为 `cognate-server cache repair --data-dir <绝对路径> --sha256 <小写SHA256> --archive-file <可信本机归档绝对路径>`；须先停止服务，仅支持 Linux legacy 数据布局。
- 修复不下载替代文件，不删除损坏原件或残留，不提高缓存预算，不等于完整数据库或灾难恢复；完整限制见 `docs/CACHE-MAINTENANCE.md`。
- 懒猫沿用 Exec 启动、首次管理员向导、原密码、原主密钥和私有数据目录；离线维护须显式指定 `/lzcapp/var/cognate/data`。
- 写入结果不明时先核对归档，不自动重试；反馈不要附带 token、密码、主密钥或完整私有配置。
