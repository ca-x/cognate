# 导入来源登记与 GitHub 代理验收

日期：2026-11-07。基线：`a350ccef4b3bc225ce79a4c087bc45255c97024e`。
本轮是源码维护阶段，不创建新的 Server、CLI、GUI 或懒猫发布标签；此前已发布的
Server/LazyCat 0.6.2 不包含这些改动。

## 用户问题与修复

- Magpie 备份中的技能曾要求资料库已有对应的已验证技能，空库时无法选择。
  Web 的 Magpie/cc-switch 导入现在显式请求 `register_sources`，冷库技能可选为来源引用。
- 仓库导入曾在整仓下载和扫描成功后才写入记录。现在先在短事务内保存私有仓库来源、
  技能引用、配置资产与终态回执；导入本身不访问 GitHub。用户随后点击“同步技能”才
  整仓获取并扫描，失败仍保留来源，能够配置代理后重试。
- 来源不是已验证内容，没有伪造归档或技能 hash，不进入公开目录、Pack 或安装 API。
  空路径表示来源未提供路径，只有显式 `.` 表示仓库根目录；cc-switch 本机目录不猜测
  为远端路径。删除来源不删除已收录内容。
- 管理员在“服务端日志 → GitHub 网络代理”保存 HTTP/HTTPS/SOCKS5/SOCKS5h 正向代理。
  设置加密持久化、revision CAS、新请求热生效；只用于指定 GitHub HTTPS 域名，保留
  TLS 和目标校验，不转写第三方下载镜像。清除设置恢复环境代理，不保证直连。

## 真实备份的有限验证

使用用户授权的本机原始 Magpie 加密导出，通过实际 Web 解密/过滤函数生成最小来源
投影，再在隔离的本机 HTTP/SQLite 与浏览器中运行。不上传原备份到外部服务，不拉取
任何真实仓库，不把原文、名称、凭据、投影或私有截图加入 Git。

结果：**14 个仓库来源、35 条技能引用、0 次仓库网络请求**。HTTP 提交与重启后读取
通过；实际浏览器确认空库技能可选、仅选技能时隐式登记仓库、提交回执与来源列表可见。
1280px 与 390px 页面未横向溢出。原件 SHA-256 及设备、inode、大小、mtime、权限均
保持不变；测试密文副本、投影、私有日志与截图在核对后清理，仅保留匿名计数。

公开测试默认只用合成数据；`TestMagpieSourceReferenceHTTPRoundTrip` 的可选本机
`COGNATE_MAGPIE_LIBRARY_FIXTURE` 不硬编码用户路径，也不输出候选内容。

代理集成使用受控本机代理与测试 TLS 信任，不代表已经测试用户实际代理、懒猫盒子或

完整 `git diff --check` 会提示该生成行；未手改生成输出，Buf 重新生成逐字节比对通过。

## 保留的失败与回归过程

1. 初始冷库测试先出现技能不可选择的失败，改为来源登记后通过。
2. 来源容量测试发现 `FinishImportSelection` 的浅复制会污染调用方 slice；数据库虽回滚，
   后续失败回执仍携带已填的来源 ID。入口分别 clone outcomes 与 skill sources 后，
   256 来源溢出与 512 技能引用边界/回滚测试通过，未放松成功状态或事务约束。
3. 新 schema 增大合法预算后，旧 R553 负控不再越界。将实际二进制负控改为 R554，仍在
   引擎前拒绝；保留旧算术负控与严格 schema 校验，实际二进制集成测试通过。
4. 首轮全量发现已有桌面测试注入 opaque `http.DefaultTransport`，以及重复实例 owner
   错误类别变化。空代理改为只包装 caller-owned RT、不关闭它；显式代理仍拒绝静默
   降级。App 保留原同目录 owner 错误合同；相关桌面/服务端包在后续全量中通过。
5. 首轮高负载运行的日志进程协调与恢复关闭测试曾失败，原断言和代码均未修改，独立
   复跑两包通过。后续 `-p 2` 全量中，恢复 worker 的 `statement-5` 一次返回
   `ErrRestoreUnsupported`，不满足预期 `ErrRestoreUncertain`；该全量命令因此不算通过。
   完整 `TestRestoreRevokeActualWorkerFaults` 独立连续五轮通过，暂不能据此断言该次失败
   的根因或其永久消失，未放宽隔离与不确定状态断言。
6. 最终以 `CGO_ENABLED=0 go test -mod=readonly -p 1 ./... -count=1` 串行运行整个仓库，
   53 个测试包通过、78 个包无测试，命令退出 0；其中 state 整包 110.763 秒、HTTP
   整包 155.969 秒，包含新技能引用配额测试。保留前述失败记录，不以本次通过掩盖
   已观察到的间歇性恢复测试问题或宣称其根因已修复。

## 维护边界

- 正常保存与移除代理无需重启；持久化状态不确定时 manager 持续 fail-closed，重读也
  不能恢复，须处理存储故障后重启。UI 不自动重发更新或导入提交。
- 来源和回执的原子性已有边界回归，但不宣称新增来源表所有存储故障点均已穷举。
- 普通备份恢复不覆盖实例网络参数；迁机须重新设置代理并保留原 master key。
- 不扩大完整配置导入、原生 GUI、跨平台本机安装、完整恢复或其它未完成需求的验收。
