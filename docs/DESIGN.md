# Cognate 管理面板设计约定

服务端面板使用已确认的 React 19、Vite、Tailwind v4、shadcn/ui 与 TanStack Query/Router。MyGo 桌面端使用原生组件，界面不共享。

## 视觉与交互

- 以资料库工作空间为布局：固定导航、清晰页标题、列表优先、操作就近，避免营销页式大标题和虚构统计。
- 使用用户提供的服务端 Logo；中性色界面与蓝色动作强调对应 Logo 的金属与蓝色元素。字体使用系统字体，仓库名用系统等宽字体，无外部字体请求。
- 所有输入有可见标签，主要操作和导航至少 44px 高；保留键盘焦点，错误靠近对应表单。
- 读取状态明确区分加载、未连接、空结果和请求失败，不用样例数据代替实际结果。
- 登录态保存在页面内存，退出时清理查询缓存；GitHub token 输入不持久化，提交后清空。
- 列表浏览即时切换。按钮仅使用 120ms CSS transform 按压反馈，目的为确认输入；减弱动态效果时移除位移，保留焦点和颜色反馈。无需额外动画库。
- 375px 起支持单列布局；导航在窄屏上变为横向顶栏，内容无需横向滚动。

使用 `ui-ux-pro-max` 做过两次设计检索，结果偏向文档或营销首页，不采用其页面结构。当前工作空间布局依照技能内置的可访问性、表单与导航规则；细节遵循 `emil-design-eng`、`apple-design` 与 `animate`。
