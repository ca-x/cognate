# Cognate 首批组件预览版

这是可供真人测试的预览版，不是完整功能正式版；未完成功能集中列在 [TODO](TODO.md)。服务端、CLI、GUI 独立发布，版本不要求一致。

## 服务端 `server-v0.1.0-rc.2`

1. **聚合与分发**：管理仓库、分类和 Pack，支持公开技能目录、匿名安装，以及由服务端代理的私有来源获取与更新。
2. **账号与管理**：提供本地账号、可选 OIDC、MCP 管理权限、文件日志设置，以及中英与主题切换。
3. **配置资产**：管理已支持的私有 AI 配置，完整 agent 应用矩阵、Pack 自动应用和云端备份恢复仍未完成。

镜像：`ghcr.io/ca-x/cognate:server-v0.1.0-rc.2`，目标为 Linux amd64/arm64，不更新 `latest`。
部署须持久保存数据及外部主密钥，并通过 HTTPS 或可信私网访问；升级前停机备份数据目录及原主密钥，不能把内部快照库当作可用备份入口。

## CLI `cli-v0.1.0-rc.1`

1. **技能安装**：提供浏览、公开安装、Pack 订阅及同步，实际安装和订阅运行支持仍限 Linux。
2. **私有管理**：Linux 可用 `auth run` 在真实终端登录后执行指定所有者命令，无需把会话放进命令参数或环境变量。
3. **安全确认**：配置修改保留预览、明确批准及冲突检查，断线后的非零结果不代表回滚，不要直接重放写操作。

分发 Linux/macOS/Windows 的 amd64/arm64 归档和 `SHA256SUMS`；可构建不等于所有平台均可安装或应用配置。
`auth run` 的明文 HTTP 仅接受字面量回环地址，例如 `http://127.0.0.1:8080`，不接受 `http://localhost:8080`。

## GUI `gui-v0.1.0`

1. **原生客户端**：使用 MyGo 原生窗口，提供本地账号登录、公开目录、Pack 订阅及明确启停的同步。
2. **配置预览**：提供已支持的 Claude 配置编辑及 Linux 本机应用、状态与恢复入口，其它 agent 不保证同等能力。
3. **安装包**：提供 Linux 归档及 Debian 包、Windows Setup 和 macOS DMG，均为预览分发。

GUI 内部包版本为 `0.1.0`，GitHub Release 仍标记为 prerelease；macOS 仅 ad-hoc 签名，未经 Developer ID 签名或公证，Windows 安装包未签名。
macOS/Windows 的技能安装、订阅生命周期和原生配置应用尚未取得完整运行资格，不要把安装包存在当作能力已验证。

## 数据兼容与反馈

新 Codex 操作记录可能使用 effective-v2 身份，旧版可能拒读；不要假定直接换回旧二进制即可安全降级，生产 Codex Apply 当前仍关闭。
优先在隔离账号、目录和非生产配置中试用；反馈请附组件版本、操作步骤和脱敏错误，不提交 token、密码、主密钥或完整私有配置。
