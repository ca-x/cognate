# Cognate 首个正式组件版本

2026-11-01 按组件独立发布：服务端 `server-v0.1.0`、CLI `cli-v0.1.0`、桌面端 `gui-v0.1.2`。旧 `gui-v0.1.0` 是已公开的预览标签，`gui-v0.1.1` 被打包前置检查拦下，两者保持不变；新桌面版本与 `mygo.json` 一致。

这是现有已验收能力的正式分发，不表示需求文档中的全部功能已经完成。发布结果以 Actions、实际下载校验和商店回执为准；本文不预先声明发布成功。

## 服务端 0.1.0

1. **技能管理**：集中管理公开及私有仓库、技能分类和 Pack，仓库可显式公开，访客无需 token 即可浏览和安装公开技能。
2. **配置管理**：管理 AI 客户端配置、私有 MCP 连接资产和 Pack 配置附件，编辑保留明确审阅、冲突检查及凭据保护。
3. **管理后台**：提供主题与语言切换、MCP token 管理、文件日志和首次管理员初始化，支持 GitHub 与 OIDC 配置。
4. **备份**：管理员可使用已提供的加密备份及显式启用的定时备份；完整灾难恢复发布与自动保留回收尚未完成，不应据此替代既有备份方案。

Docker 提供 Linux amd64/arm64，标签为 `ghcr.io/ca-x/cognate:server-v0.1.0`；不创建隐式 `latest` 标签。懒猫继续使用独立 Exec LPK，仅发布喵喵商店。

## CLI 0.1.0

1. **技能使用**：浏览和安装公开技能，管理 Pack 订阅与同步，受验收的实际安装流程以 Linux 为准。
2. **私有操作**：Linux `auth run` 通过真实终端登录并执行所有者命令，避免把会话放进参数或环境变量。
3. **配置应用**：保留明确预览、授权及冲突检查，仅开放已验收的固定 agent、版本和平台组合，不把单个 Codex 组合的支持扩大到所有客户端。

提供 Linux/macOS/Windows 的 amd64/arm64 归档、Codex 许可证和 `SHA256SUMS`。归档可构建不等于各平台均可安装或应用配置；跨平台登录及 OIDC 的 CLI 闭环仍待完成。

## Desktop 0.1.2

1. **原生客户端**：使用 MyGo 原生组件浏览技能、管理订阅和配置资产，支持主题及语言切换。
2. **选择导入**：从已支持的来源选择 skills、仓库及配置，上传需独立批准，三类默认不勾选，提交前统一审阅。
3. **配置资产**：编辑私有 MCP 配置、调整配置分区顺序和维护 Pack 有序附件，未知提交结果只读核对，不直接重放写操作。

Linux 已有真实窗口的有限流程验收；macOS/Windows 安装、完整交互及配置应用仍未取得完整运行资格。macOS 包仅 ad-hoc 签名且未公证，Windows 安装包未签名；这些状态不会因正式版本号改变。

## 升级与已知限制

- 升级前保留数据库、归档和原主密钥；已有数据丢失密钥时拒绝重新生成，首次管理员设置不覆盖已有账号或密码。
- 数据与操作记录可能使用新格式，旧程序可能拒读；不要假定直接换回旧二进制就能安全降级。
- Pack 附件目前主要用于所有者元数据管理，不代表客户端已经获得消费权限或会自动应用；完整配置消费与自动应用继续在 `TODO.md` 跟踪。
- 完整备份恢复、保留回收、所有 agent 矩阵、跨平台原生体验、签名和全站 UI 逐页验收仍在推进。
- 懒猫用户已确认此前版本安装成功；新版本的真机升级、平台 OIDC 和用户数据保留仍需真人测试，不以商店接受代替。
- 断线后的写入结果不明不等于回滚；先查询原操作状态。反馈不要附带 token、密码、主密钥或完整私有配置。
