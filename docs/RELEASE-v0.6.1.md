# Cognate 0.6.1

状态：维护版本待发布，最终分发记录以 `RELEASE-v0.6.1-VERIFICATION.md` 为准。

- 导入文件选择后显示文件名与大小，支持 Magpie 原生备份后缀；候选按技能、仓库与客户端配置分列搜索和选择，重复提示合并，技术详情按需展开。
- 修复 cc-switch 大库预览误用单次提交数量限制，以及排除提示取消后重勾导致的提交失败；仅选仓库也可以导入，完成后显示可读结果。
- 管理员可以在“管理 → 服务端备份”设置启停、自动周期和 S3 目标，保存后在线生效，不需要重启；运行中的任务或待核对结果会阻止不安全的配置切换。
- GitHub token 获取及权限说明加入来源页和文档；OIDC 会话使用已验证的显示名称，关联当前登录服务后不再提示重复绑定。

## 升级须知

支持在线备份的 Linux 服务端现在同一数据目录仅允许一个实例，即使备份关闭也是如此。
升级前请停止共享该目录的其它服务端；不同目录仍可独立运行。懒猫包装原本就配置为
`multi_instance: false`。账号、原有数据与主密钥不重新初始化。

备份目标凭据加密保存，不回显已有秘密值。独立恢复密钥仍需由部署者提供已有的
32 字节私有文件并另存离线副本；页面填写的是服务端路径。已有命令行参数作为未保存
Web 设置时的初始配置，保存后使用持久化的页面设置。

本次发布服务端与懒猫包装，不重发未修改的 CLI/GUI。技能导入不等于安装，配置导入
不会自动应用到设备，来源密钥不迁移。完整恢复、外部 S3 供应商与懒猫真机升级仍需
单独验证，不能以此版本的备份设置验收代替。
