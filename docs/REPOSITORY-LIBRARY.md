# 服务端仓库资料库

## 当前能力

- `skillhub.library.v1.LibraryService` 提供收录、列仓库、仓库技能详情与所有者显式刷新；全部要求本地/OIDC 共用的 Bearer 会话，详情与刷新在访问内容前按用户过滤。
- 收录固定访问 `codeload.github.com` HTTPS，不接受任意 URL host、文件路径、客户端传入的 hash 或认证头；不跟随重定向，也不继承 HTTP cookie jar。当前仅支持公开归档。
- 整仓下载后在有界 Afero MemMapFs 中校验/扫描；隐藏 skill 目录参与扫描，链接与非普通内容不提取，路径遍历、重复条目、额外根目录、损坏 gzip 和非零未扫描尾部均拒绝。
- 接受 GitHub 的首个 global PAX `comment` 元数据头，要求恰有这一条记录；结构性字段和解析异常被拒绝。Go tar 对部分错误 global PAX 会返回空记录，不能把空记录视为安全。
- `CollectedRepository` 按用户、规范 owner/name、分支唯一，`CollectedSkill` 按仓库/路径唯一。技能 hash 包含普通文件、二进制和可执行位。默认分支/HEAD 是同一身份，指定分支为单独快照。
- Afero 的受限 `os.Root` 适配器写入私有归档，`ReadOnlyFs` 读取；临时文件同步后，以不可覆盖的 hard link 发布内容 hash 对象并同步目录，再提交数据库事务。缓存路径不作为 RPC 输入暴露。
- 收录与详情 hash 校验共用两个 IO 槽位，超出即返回容量错误；请求最长 20 秒。关闭先拒绝新工作、取消已有工作、等待退出，再关闭缓存/数据库。

## 容量与失败

- 32 MiB 压缩归档、64 MiB 普通文件、80 MiB 完整 tar 解压字节、10000 个归档条目、512 个技能、每份 SKILL.md 1 MiB；元数据名称最多 256 字节，描述最多 4096 字节。
- 每用户最多 1000 条收录记录，下载前预检，写入事务再次检查。完整缓存默认对象预算 512 MiB，可在首次初始化时用服务端 `--archive-cache-bytes` 指定，上限 1 TiB；零值取默认。
- 跨进程文件锁串行容量核验/发布。预算以私有 `.cache-budget` 绑定目录，不一致配置拒绝启动；每次写入再次检查该策略。当前不提供在线改预算，不能通过第二实例的较大配置绕过既有上限。
- 统计包含普通对象、未引用归档及中断 stage，重复对象不重复占用预算；固定的预算/锁控制元数据及文件系统元数据开销不计入对象预算。预算满时拒绝新对象，不自动删除已引用内容。
- 发布后事务失败/进程崩溃可能留下无引用对象。当前只保证其受总预算约束，尚无自动 GC；目录所在文件系统的临时写入与文件元数据仍有额外开销。
- 列表只读取元数据；详情与重复收录流式验证保存归档的 SHA-256，包含并发唯一键冲突后最终返回的记录，缺失/损坏返回 `data_loss`。校验不能保证返回后对象永不被外部删除；重复收录仍不刷新或自动修复该快照，刷新使用独立接口。
- 用户“停止等待”是取消请求，不是撤销已提交事务。网页说明提交可能已完成，并重新读取列表。

## 显式源刷新

`RefreshRepository` 接收已收录仓库 ID、`expected_archive_hash` 和正数 `expected_publication_revision`。Repository 的新增字段 8 提供当前 publication revision；既有字段及 wire namespace 不变。客户端先读取当前版本，冲突后重新读取，不猜测 revision，也不能上传归档/hash/skill 列表替代服务端抓取。

通过 owner/版本预检后，服务端从数据库中保存的 GitHub 身份与分支重新下载、完整扫描，先持久化不可覆盖的新归档，再在同一 SQLite 写事务中核对原版本并替换内容。`publication_revision` 同时作为源归档/发布代次，防止 A→B→A 后旧确认重用。相同 path 保留 skill ID 和分类；新增 path 分配新 ID，不自动加入 Pack；每个受影响 Pack 在同一事务中只推进一次 revision，成员/别名和分享 token 不变。只有归档包装或非 skill 文件变化且 Pack 可见内容相同时，不推进该 Pack 版本。

被 Pack 引用的删除/改名、同别名内容分叉和已公开仓库的任何归档变化均整次拒绝。公开仓库须先独立取消公开，再刷新，检查完整内容后另行确认公开；不能用刷新静默公开新附件或目录。源故障、超限、取消、CAS/引用冲突不替换旧可用内容；已写但未提交的新对象仍计入缓存预算，不自动删除或覆盖旧对象。

RPC 成功返回提交时的版本和变更计数/受影响 Pack，不在提交后重读另一个版本。无效输入为 InvalidArgument，旧版本为 Aborted，发布/引用/别名冲突为 FailedPrecondition；跨 owner 与不存在均为相同 NotFound。底层抓取和数据库错误不原样回显。

旧缓存对象保持不可变，刷新不新增旧版本下载授权。已有 Pack/public 下载继续按原先逐块与 final 前核验当前授权；提交前已通过检查的一块甚至 final 可能延后发出，检查和发送并非原子，已发字节也无法收回。

本片提供 owner RPC，不是 Web 刷新按钮、已收录源的定时更新、私有仓库获取或缓存 GC。客户端持续同步只能获取服务端已经更新的 manifest，不能替代这里的抓取与提交。

## 整体进度边界

Lists 定时增量收录、Pack/分享/流式分发、客户端订阅与去重、公开目录及 MyGo 原生界面/打包已有各自限定交付，参见对应专题文档，不能再视为从零未实现。已有源自动刷新、私有内容、GC、完整跨平台安装/恢复、S3 灾备、完整配置导入及原生配置应用仍需继续；本资料库切片不等于 M3/M4 或首版发布完成。
