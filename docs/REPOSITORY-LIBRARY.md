# 服务端仓库资料库

## 当前能力

- `skillhub.library.v1.LibraryService` 提供收录、列仓库与仓库技能详情；全部要求本地/OIDC 共用的 Bearer 会话，详情在访问内容前按用户过滤。
- 收录固定访问 `codeload.github.com` HTTPS，不接受任意 URL host、文件路径、客户端传入的 hash 或认证头；不跟随重定向，也不继承 HTTP cookie jar。当前仅支持公开归档。
- 整仓下载后在有界 Afero MemMapFs 中校验/扫描；隐藏 skill 目录参与扫描，链接与非普通内容不提取，路径遍历、重复条目、额外根目录、损坏 gzip 和非零未扫描尾部均拒绝。
- 接受 GitHub 的首个 global PAX `comment` 元数据头，要求恰有这一条记录；结构性字段和解析异常被拒绝。Go tar 对部分错误 global PAX 会返回空记录，不能把空记录视为安全。
- `CollectedRepository` 按用户、规范 owner/name、分支唯一，`CollectedSkill` 按仓库/路径唯一。技能 hash 包含普通文件、二进制和可执行位。默认分支/HEAD 是同一身份，指定分支为单独快照。
- Afero 的受限 `os.Root` 适配器写入私有归档，`ReadOnlyFs` 读取；临时文件同步后，以不可覆盖的 hard link 发布内容 hash 对象并同步目录，再提交数据库事务。缓存路径不作为 RPC 输入暴露。
- 收录与详情 hash 校验共用两个 IO 槽位，超出即返回容量错误；请求最长 20 秒。关闭先拒绝新工作、取消已有工作、等待退出，再关闭缓存/数据库。

## 容量与失败

- 32 MiB 压缩归档、64 MiB 普通文件、80 MiB 完整 tar 解压字节、10000 个归档条目、512 个技能、每份 SKILL.md 1 MiB；元数据名称最多 256 字节，描述最多 4096 字节。
- 每用户最多 1000 条收录记录，下载前预检，写入事务再次检查。完整缓存默认对象预算 512 MiB，可在首次初始化时用服务端 `--archive-cache-bytes` 指定，上限 1 TiB；零值取默认。
- 跨进程文件锁串行容量核验/发布。预算以私有 `.cache-budget` 绑定目录，不一致配置拒绝启动；每次写入再次检查该策略。当前不提供在线改预算，不能通过第二实例的较大配置绕过既有上限。
- 统计包含普通对象、未引用归档及中断 stage，重复对象不重复占用预算；固定的预算/锁控制元数据及文件系统元数据开销不计入对象预算。预算满时拒绝新对象，不自动删除已引用内容。
- 发布后事务失败/进程崩溃可能留下无引用对象。当前只保证其受总预算约束，尚无自动 GC；目录所在文件系统的临时写入与文件元数据仍有额外开销。
- 列表只读取元数据；详情与重复收录流式验证保存归档的 SHA-256，包含并发唯一键冲突后最终返回的记录，缺失/损坏返回 `data_loss`。校验不能保证返回后对象永不被外部删除。目前不自动修复或更新该快照。
- 用户“停止等待”是取消请求，不是撤销已提交事务。网页说明提交可能已完成，并重新读取列表。
