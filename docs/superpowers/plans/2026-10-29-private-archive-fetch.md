# S1a: owner-authorized private archive transport

Base: `47bb9165d59e6ebb2a58ad756903e700cfe4762c` (tree `fdc0db900263942ede8f24246bbfa2f98b70d21a`). This slice adds only `internal/repository/private_archive.go`, `internal/repository/private_archive_test.go`, and this plan. It does not wire private sources into library, state, Lists, workers, RPC, or clients.

Implement `(*ArchiveFetcher).FetchPrivate(ctx, reference, github.Token, check func(context.Context) error)`. The caller supplies a short authorization check that releases database transactions/locks before returning; HTTP never runs inside that callback. Reject nil checks and unusable tokens. Check authorization before each request, between hops, after reading the archive, and before returning the scanned snapshot. Do not return arbitrary callback, transport, URL, or response errors containing secrets.

Use a single 20-second context budget (also bounded by caller/token expiry), the existing fetcher's shared cooldown, and existing archive inspection limits. GET only fixed HTTPS `api.github.com/repos/{owner}/{repo}/tarball`, omitting the default ref and escaping an explicit branch as one segment. Send the GitHub Bearer only to that API request. Accept exactly one 302 Location, bounded to 8 KiB, with HTTPS and exact `codeload.github.com` authority (optional explicit port 443), no userinfo or fragment. Make a fresh second request, without Bearer, cookies, proxy credentials or Referer, and accept only 200. Neither hop follows automatic redirects. There is no public fallback or automatic retry. Both hops recognize 429 and 403 with Retry-After and update the same existing cooldown.

The implementation ruling permits using GitHub's returned temporary capability URL, including its query, only in memory for this fetch. Never construct a token URL or persist, log, wrap in errors, or return the Location. GitHub documents a five-minute lifetime but does not fix the URL/query syntax: https://docs.github.com/en/rest/repos/contents#download-a-repository-archive-tar .

Use TDD at the authorized FetchPrivate/HTTP/check/cooldown seams: first a real synthetic HTTP API→302→codeload archive succeeds; then authorization, malicious redirects, privacy, cancellation, limits, shared deadlines/cooldown, and concurrent public/private callers. TLS test servers are reached only through a transport mapping the two fixed production hosts to loopback. All tokens and URL capabilities are synthetic; no real HOME configuration or credentials are read. Prove negative controls reject missing authorization, missing query capability, and invalid archives. Existing public tests must continue passing.

Verify with Go 1.27.3 and `CGO_ENABLED=0 go test ./internal/repository ./internal/github -count=1`, focused repetition, `CGO_ENABLED=0 go vet ./internal/repository ./internal/github`, and `gofmt -l` on the two new Go files. Do not modify `archive.go` or `archive_cooldown.go`, stage, commit, push, or spawn agents. Report evidence, exact new-file manifest/blob hashes, and a virtual base-plus-slice tree hash in ignored `.superpowers/sdd/2026-10-28-release/private-archive-fetch-report.md`; this is not complete S1 private-source functionality.
