# 归档缓存维护入口

目标是补齐 TODO 中缓存完整性修复与故障恢复，而不是让普通刷新静默覆盖损坏文件。

## 第一片：显式离线校验

- 命令：`cognate-server cache verify --data-dir /absolute/private/data --sha256 <lowercase-sha256>`。
- 仅 Linux；必须显式指定绝对数据目录与准确 SHA256，不推断默认实例，不读取主密钥。
- 持现有 runtime EX，在线服务运行时等待且可取消。借用持锁目录 FD，不重新沿用户路径访问归档。
- 仅支持 legacy 布局；存在运行代、restore 或 intent 痕迹拒绝，避免校验错误运行代。
- 目录与文件必须属于有效用户且私有；拒绝 symlink、hardlink、FIFO、设备和越界文件。
- 文件最大 32 MiB，完整核对压缩字节 SHA256 并调用现有归档语义检查；不输出内容、路径或凭据。
- 不创建缓存、不改归档、不碰业务数据库；仅 runtime 锁协议可能初始化协调文件。
- 仅所有读取、语义检查、目录身份复查和 Close 成功后输出校验成功。
- 测试覆盖真归档成功、同尺寸损坏、合法哈希但非法归档、缺失、权限、链接、特殊文件、
  运行代痕迹、显式参数、取消与在线锁阻断；负例不能靠编译错误。

## 后继：显式修复及回收

校验入口不是修复完成。后续修复需显式提供正确归档并核对同一 SHA256；在 EX 内验证
预算包含旧损坏原件和 staging，使用原子交换保留旧原件，不降级为覆盖写；完整证明
Sync/Close 不明、取消、身份替换及进程中断的状态。运行代布局由 R3 接入后独立开放。
无引用对象回收还需同切点数据库引用闭包，不能按文件年龄删除受引用归档。
