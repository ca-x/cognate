# 首次管理员初始化

`cognate-server` 提供显式、仅进程启动时使用的首次管理员初始化，不暴露初始化 RPC：

```sh
cognate-server --data-dir /absolute/private/data --key-file /absolute/private/master.key \
  --bootstrap-admin-username admin \
  --bootstrap-admin-password-file /absolute/private/bootstrap.password
```

密码文件须为当前用户拥有的私有普通文件（Unix 下 `0600`、父目录 `0700`），8–1024 字节；原样读取，不剥离换行。不支持密码命令参数或密码环境变量。请用密码管理器创建文件，不把密码放入 shell history、日志或工单。初始化后可移除该输入文件，但重启时保留两个参数，用户名保持一致；已初始化时不读取密码文件，不重置密码。

首次创建只允许没有任何用户的实例：User、本地 Argon2id 密码 hash 与 AEAD 绑定的初始化身份记录在同一个 SQLite 事务提交。失败不留下半个账号；提交结果不明确时不自动重试写入。重启核对绑定与同一个本地账号后，仅把其 UUID 加入已有管理员 allowlist。用户名大小写按既有本地账号规则归一化；切换到另一个用户名、绑定损坏或丢失均拒绝，不能自动接管已有账号。

已有用户且没有初始化记录的实例应继续使用重复的 `--admin-user-id` 显式授权，不得用初始化流程提升普通账号。最多 32 个管理员；同时使用初始化时，显式 UUID 最多 31 个。管理员权限沿用现有全局日志管理，不授予其他用户私有技能或凭据的访问权。禁用初始化参数会移除该启动来源的授权，不删除账号；仍可显式授权其 UUID。

懒猫安装向导提供首次用户名、secret 密码、显式 UUID、OIDC 开关和公开 GitHub client ID。密码由平台 secret 参数传给包装脚本，脚本用私有文件交接并在 exec 前清除原密码环境变量；该受限输入文件位于私有 keys 目录，不是加密数据库的一部分，升级不会用它重置已有密码。主密钥仅缺失时创建；不修复、不覆盖已有错误大小、权限不安全或符号链接密钥。

本轮本地复现了祖先挂载路径别名触发严格主密钥检查失败的情形；包装脚本创建状态目录后使用物理规范路径，保留 key/data 叶节点符号链接拒绝和核心验证。用户懒猫盒子没有可用安装环境，未获取设备元数据，也没有真机验证，不能由本地复现推断其设备上所有失败原因。
